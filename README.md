# 训练过程记录导出（只读副本）

这是一份**训练过程记录的自包含导出副本**，用于在无法访问原始平台的情况下查看实验过程。它不是源码仓库，也不包含模型权重、训练数据或可执行代码。

- **原始运行位置**：SwanLab 上的一个**私有项目**（未公开，外部无法直接访问），因此导出成本目录。
- **导出时间**：2026-11-19（Asia/Shanghai），一次性快照；导出后云端新增的运行不会出现在这里。
- **导出方式**：通过平台开放接口只读拉取（运行列表、指标序列、指标汇总），未对云端做任何修改。
- **记录范围**：243 条运行；其中 33 条关键运行保留了逐次指标序列，其余仅在索引中出现。

## 文件结构

```
.
├── runs_index.csv           # 243 条运行索引（一行一个 run）
├── runs_index.json          # 同上，JSON 形式
├── summary_wide.csv         # 243 行 × 125 指标列，每个 run 每个指标的末次值
├── csv/<run_id>_<name>.csv  # 33 条关键运行的逐次指标（一行一个数据点）
└── plots/*.png              # 4 张代表运行曲线（由同目录 CSV 直接绘制）
```

## 字段含义

### runs_index.csv / runs_index.json

| 字段 | 含义 |
|---|---|
| `project` | 运行所属项目标识 |
| `run_name` | 运行名称（含实验臂与批次信息，如 `real-fd001`） |
| `state` | 运行状态，绝大多数为 `FINISHED` |
| `created_at` / `finished_at` | 平台记录的创建/结束时间，**是上传记录时间，不是训练墙钟时间** |
| `run_id` | 平台内运行唯一 ID，也是 `csv/` 文件名前缀 |
| `group` | 分组标签，未分组时为空 |

### summary_wide.csv

第一列为 `run_name`/`run_id` 等标识，其余每列一个指标，取该指标最后一个值。指标包括评估类（如 `eval_rmse`、`eval_mae`、`eval_accuracy`）、决策类（如 `accept_n`、`det_delay_mean`、`labels_used`）与系统类（耗时、内存等）。

### csv/<run_id>_<name>.csv

| 字段 | 含义 |
|---|---|
| `key` | 指标名 |
| `step` | 记录步序号，**唯一可靠的先后依据** |
| `value` | 指标值 |
| `timestamp_ms` | 平台时间戳（毫秒）。部分运行的全部数据点时间戳相同，不可当作真实时间轴 |

### plots/*.png

每条运行取 6 个有变化的指标画小图，横轴一律为 `step`。指标优先按语义（评估指标、决策指标）选取，不足时用波动幅度补足。

## 阅读时需要知道的三点

1. **时间字段是上传时间，不是训练时间**：不要用它推断实验真实先后或耗时；2026-11-05 那批为历史上传时统一回填，大量运行集中在一小段时间内。
2. **部分运行（如 `rebaseline_eval_v1`）的全部数据点时间戳完全相同**，这类运行只能靠 `step` 区分先后，不能画成时间轴。
3. **本目录含合成数据上的实验记录**：这些运行仅用于内部流程追溯，**不能作为任何对外效果或性能证据**引用；只用真实数据集上运行的结果作参考。

## 关于本目录的边界

- 不含任何凭据、令牌、账号密码；不含原始训练数据与数据行；不含模型权重或检查点文件。
- 不含指向私有仓库或私有项目页面的链接；运行标识仅以 `project` / `run_id` 文本形式保留，供内部核对。
- 本目录为研究/工程过程记录，指标数值的解释权归原项目内部结果文档，导出物本身不构成结论。
